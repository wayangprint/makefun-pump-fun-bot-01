A volume-surge breakout trading bot for pump.fun bonding curves (agent-fun/replay/v2). It buys a coin when its trade activity surges — the recent trade rate at least triples the longer baseline, with net SOL flowing in and the price up — then sells the whole position on a fixed take-profit, a fixed stop-loss, or a time limit. One fixed buy per position, no pyramiding.

## Run it

```sh
node main.ts
```
